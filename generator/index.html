How the generator works

This generator outputs CS2 console variables such as cl_crosshairstyle, cl_crosshairsize, cl_crosshairgap, cl_crosshairthickness and color/outline controls. It does not pretend to generate a Valorant profile code.

Importing a share code

For a CS2 share code, use the game's Crosshair settings and choose Share or Import. The generator's Copy configuration button instead gives you console commands for the selected settings.
