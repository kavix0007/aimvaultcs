How to Change a CS2 Crosshair

Learn how to import a CS2 crosshair share code and how console configuration differs from a share code.

Import a CS2 share code

Open CS2 and go to Settings → Game → Crosshair → Share or Import. Paste the share code and import it.

Use console commands

AimVaultCS's generator can output console variables such as cl_crosshairstyle, cl_crosshairsize, cl_crosshairgap and cl_crosshairthickness. Copy the generated configuration and run it in the developer console.

Keep a backup

Save your preferred configuration before experimenting so you can restore it quickly.
