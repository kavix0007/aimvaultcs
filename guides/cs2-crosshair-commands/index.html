CS2 Crosshair Console Commands

A reference for the main CS2 crosshair console commands used to recreate and tune a crosshair.

Core CS2 crosshair commands

Common variables include cl_crosshairstyle, cl_crosshairsize, cl_crosshairgap, cl_crosshairthickness, cl_crosshairdot, cl_crosshair_drawoutline, cl_crosshairalpha and the color variables.

Why commands are useful

Commands make a configuration easy to document and reproduce. They are also useful when you want to compare two settings one variable at a time.

Use the generator

Instead of typing commands manually, use the CS2 Crosshair Generator to build and copy a configuration.
