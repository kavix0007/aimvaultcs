How to Import a CS2 Crosshair Code

Learn how to import a CSGO- formatted CS2 crosshair share code and where to find the Share or Import option.

Open CS2 Crosshair settings

Open Counter-Strike 2 settings and go to the Crosshair section. Look for the Share or Import control associated with the crosshair preview.

Paste the share code

Copy the complete CSGO-xxxxx-xxxxx-xxxxx-xxxxx-xxxxx code and paste it into the import field. Confirm the import and check the preview before entering a match.

Share your own setup

The same Share or Import area can be used to generate a share code from your current crosshair. Save the code somewhere if you want to restore it later.
